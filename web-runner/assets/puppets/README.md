# Chibi puppet pilot (ORKA-t1m)

Fara follows the existing blue-genie combat sprite. Gobloc follows the existing enemy identity with Fara's chibi proportions and paint style. Original gameplay sprites are unchanged.

`source/parts-*-v1.png` preserves each generated transparent atlas. `parts.json` records mechanical crop boxes; separate PNG parts retain hidden joint paint. `*.sif` are editable Synfig bone sources with parented arms/legs and bitmap layers bound through native `bone_link` transformations. The two atlas sheets have one authored facing each. Opposite views mirror the source; armor handedness changes and remains a review limitation.

Run `node tools/export_actor_puppets.mjs` to rebuild initial editable sources and the clip manifest. This overwrites SIF edits. Run `SYNFIG_BIN=/opt/homebrew/bin/synfig node tools/export_actor_puppets.mjs --render` to export the existing SIF files without rewriting them. Synfig 1.5.5 has been tested on the native Apple Silicon command-line renderer. GUI authoring has not been verified. Source atlas generation is creative work; mechanical crops are reproducible from recorded boxes using ImageMagick's `-crop WIDTHxHEIGHT+X+Y +repage`.

Semantic states are idle, walk, basic, cast, hurt, ko, and spawn. Source/PNG filenames retain walk/attack/hit/defeated authoring labels. Idle/walk loop, while other states hold their final frame until simulation chooses a new state. Clip duration describes presentation and grants no damage, movement, invulnerability or cooldown behavior. The independent `actorClipPlayback.mjs` loader samples the supplied frozen-aware simulation age in milliseconds. Render the returned frame at its recorded foot origin. No runtime skeleton engine is included.

Exports use 128px square transparent canvases, 12fps, with foot origin (64,125). Full source canvas is 256px; editable bitmap parts preserve atlas resolution. The manifest loads individual actor/state/facing sequences lazily. Each twelve-frame clip consumes 0.75 MiB decoded RGBA; the full 288-frame pilot consumes 18 MiB if callers load every sequence. Sharing loaded clip images across instances prevents per-enemy duplication. Actual live encounter memory remains to be measured after integration.

Neutral poses have been inspected by the builder. A fresh independent critic preferred the Fara pilot over the original static reference at matching 56px height (moderate confidence) and observed no obvious neutral joint gaps. Wrist overlap on Fara and costume overlap on Gobloc require animation review. The head pivots at the neck. Walking, defeat grounding, opposite-facing readability and the full seven-state exports await visual review; this pilot has not passed the gauntlet.

Basic clips declare `impactTimeMs` at the strongest exported strike frame (416.667ms); cast clips declare `releaseTimeMs` at their gesture peak (500ms). These markers describe the exported pose. Integration must map presentation age to the existing simulation impact/action window in one renderer seam, so strikes appear before the action state expires. Marker reads never advance damage or skill clocks.

`PUPPET_ACTOR=gobloc` or `PUPPET_CLIP=cast` can limit a `--render` rebuild after a scoped source edit. The browser preview at `output/qa/ORKA-t1m/index.html` displays normal-size motion, enlarged joints, a current-state contact sequence and a pause/peak inspection control. Enlarged views upscale the 128px gameplay exports for joint inspection.
