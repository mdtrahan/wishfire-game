# Vault Progressions

Purpose: map Vault-layer progression for non-draw systems using existing Vault skill text.
These entries are not live draw cards. They are intended for relics, account growth, and long-horizon tuning.

## Runa Totem Progression Lanes

### Totem Damage Up
- Card Text: `Aura Totem` totem DoT or pulse damage scales by a fixed tier.
- Risk: `MED`
- Note: Can accelerate boss pressure if stacked with burst lanes.
- Growth: `4% / 4% / 5% / 5% (18%)`
- Source: `Aura Totem: Burn`, `Aura Totem: Blast`

### Totem Duration Up
- Card Text: Totems persist longer and get more active turns before expiry.
- Risk: `MED`
- Note: Prolonged uptime can crowd out short encounter windows.
- Growth: `6% / 6% / 7% / 8% (27%)`
- Source: `Aura Totem: Burn`, `Aura Totem: Blast`

### Totem HP Up
- Card Text: Totems take more damage from enemy attacks before breaking.
- Risk: `MED`
- Note: Reduces enemy shutdown value by preserving setup value.
- Growth: `4% / 4% / 5% / 5% (18%)`
- Source: `Aura Totem: Burn`, `Aura Totem: Blast`

### Detonation Charge Gain Up
- Card Text: Totems store charge faster while alive.
- Risk: `MED`
- Note: Can push detonation timing into dangerous windows too quickly.
- Growth: `4% / 4% / 5% / 5% (18%)`
- Source: `Aura Totem: Burn`, `Aura Totem: Blast`

### Detonation Burst Up
- Card Text: Detonation burst payload scales up per stored charge tier.
- Risk: `HIGH`
- Note: Biggest immediate threat lane; use carefully with long-to-keep totems.
- Growth: `2% / 2% / 3% / 3% (10%)`
- Source: `Aura Totem: Burn`, `Aura Totem: Blast`

### Totem Summon Chance Up
- Card Text: Improve chance to successfully place a totem.
- Risk: `LOW`
- Note: Helps consistency without changing burst shape.
- Growth: `6% / 6% / 7% / 8% (27%)`
- Source: `Aura Totem: Burn`, `Aura Totem: Blast`

### Totem Expiry Burst Up
- Card Text: Increase burst when a totem naturally expires.
- Risk: `MED`
- Note: Strong in end-of-window pacing patterns.
- Growth: `4% / 4% / 5% / 5% (18%)`
- Source: `Aura Totem: Burn`, `Aura Totem: Blast`

### Totem Death Burst Retention Up
- Card Text: Keep more stored charge when a totem is destroyed before expiry.
- Risk: `MED`
- Note: Makes interrupt play less punishing for the player.
- Growth: `4% / 4% / 5% / 5% (18%)`
- Source: `Aura Totem: Burn`, `Aura Totem: Blast`

## Mapping Notes

Use this rule when assigning `Vault Lean`:
- Falie support and survivability skills stay in Mitigation and Threat lanes.
- Huun and economy-facing skills stay in Loop Risk, Economy Momentum, and Resource Conversion.
- Runa starts in totem lanes, then optionally adds Penetration or Stat Borrow Scaling.
- Kojonn-aligned support/utility uses Enemy Stat Leverage or Board Economics.
