# Historical Construct JSON Parity

Construct project artifacts are retired from the current game. `project_C3_conversion/` is absent from the primary checkout. For current gameplay, UI, or regression work, follow the live product and code ownership contracts and continue the requested task.

For a historical parity audit, identify the supplied JSON source path and revision and the implementation being compared. Inspect the relevant conditions, actions, values, layout geometry, and data flow. Map only the behavior in scope to its JS owner and verify it with focused checks.

Distinguish confirmed matches, intentional differences, and unexplained gaps. Cite the source rules and observed implementation evidence. If the historical source is unavailable, report that specific limitation without inventing its behavior. An audit authorizes investigation; changing gameplay requires an implementation request.
