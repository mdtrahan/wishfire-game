# Compare Implementation Approaches

Identify the unresolved decision, existing implementation, and constraints that affect the choice. Compare alternatives only when their tradeoffs can change the recommendation. When one approach clearly meets the requirements, explain it directly.

Use evidence appropriate to the decision, such as compatibility with the current architecture, maintenance cost, measurable performance, or implementation risk. Choose the number of alternatives and presentation format to fit the question. Use numerical scoring only when its criteria and weights have a meaningful basis.

Recommend an approach with its decisive tradeoff and any evidence still needed. For an implementation request, continue through the authorized changes and validation after making the decision; pause only for a consequential choice that remains unresolved.

Delegation depends on the tools and authorization available in the current environment. Simulated alternatives are drafts from one agent and should be described as such.
