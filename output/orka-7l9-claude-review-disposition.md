## Decision

Claude's main warning stands: passing zero-KO fixtures does not yet establish satisfying combat or meaningful defensive stats. The next implementation session should first measure cap activation, heal dependence, earned boss arrival, and recovery endurance. The external suggestion to copy an exact StoneAge formula or set an arbitrary minimum-HP band is unsupported. The [saved plan](orka-7l9-reference-conclusion-and-build-plan.md) carries the corrected proof order. The candidate remains provisional and unmerged.
